# PROJECT 1028 — Visual Direction v1.0

> 비주얼 디렉션의 핵심: 현실적인 한국의 외딴 섬마을을 먼저 만든다. 공포는 괴물의 외형보다 공간, 사람, 행동, 조명, 사운드의 불일치에서 만든다.

## 1. 비주얼 아이덴티티

### 1.1 한 문장

> 현실적인 한국의 외딴 시골마을에 들어갔는데, 귀신보다 그 마을 자체가 무서운 게임.

목표 그래픽은 사실적인 3D 호러 게임의 환경 표현을 기준으로 한다. 단, 서양 농장/도시/괴물 호러의 미술 언어를 그대로 가져오지 않는다.

핵심 조합:
- Photorealistic Korean Rural Environment
- Korean Island Village
- Social Horror
- Local Folklore / Urban Legend
- Uncanny Human Behavior
- Cinematic Lighting

### 1.2 공포의 우선순위

현실적인 공간 → 평범한 사람 → 미묘한 이상함 → 불안 → 의심 → 괴담 → 점프스케어

처음부터 공포 게임처럼 보이게 만들지 않는다. 낮에는 실제로 존재할 법한 한국의 시골마을이어야 하며, 플레이어가 공간에 익숙해진 뒤 같은 공간의 일부가 비정상적으로 보이기 시작해야 한다.

## 2. 지역적 배경

PROJECT 1028의 섬들은 실제 특정 지역을 그대로 복제하지 않는다. 한국 남서부 농어촌의 특징을 시각적 참고로 사용한다.

- 불규칙한 주택 배치
- 구불구불한 마을길과 좁은 골목
- 논·밭·염전·비닐하우스
- 농기계와 농자재
- 창고·선착장·방파제
- 산과 해안이 가까운 지형
- 전봇대와 전선
- 오래된 담장·장독대·마당·개집
- 어구와 작업 도구
- 오래된 트럭·경운기
- 오래된 시설과 최근 설비의 혼재

핵심은 '한국적인 장식'보다 '한국에서 실제로 사람이 살아온 흔적'이다.

### 2.1 시간의 층

오래된 주택 + 부분적으로 교체된 지붕 + 샷시 창문 + 최신 CCTV + 태양광 패널 + 오래된 농기계 + 택배 상자 + 생활 쓰레기처럼 서로 다른 시대의 요소가 섞여 실제 생활 공간처럼 보여야 한다.

## 3. 마을 구성 원칙

### 3.1 불규칙성

주택을 격자 형태로 배치하지 않는다. 집마다 방향이 조금씩 다르고, 도로가 집 사이를 피해가며, 골목은 막히거나 예상하지 못한 방향으로 연결될 수 있다. 빈 공간과 텃밭이 주택 사이에 섞이고 밭과 주거지가 완전히 분리되지 않는다. 창고와 작업 공간은 주택 가까이에도 존재한다.

### 3.2 생활 흔적

빨래, 고무대야, 농약통, 농기계, 폐타이어, 호스, 장독, 수도꼭지, 택배 상자, 낡은 의자, 쓰레기봉투, 어구, 작업복, 자전거, 개집, CCTV, 전선 등은 랜덤하게 흩뿌리지 않고 각 공간의 사용 목적에 맞게 배치한다.

## 4. 낮과 밤

### 4.1 낮

낮의 기본 인상은 평범함이다. 밝음, 평온함, 생활감, 농촌의 일상, 관광지처럼 보이지 않는 현실성을 목표로 한다. 낮부터 과도한 안개, 붉은 조명, 피, 귀신 연출 등을 사용하지 않는다.

### 4.2 해질 무렵

집 안의 불이 하나둘 켜지고, 사람의 활동량이 줄어들며, 길의 일부가 어두워지고, 먼 거리의 사람을 식별하기 어려워지는 변화로 불안을 만든다.

### 4.3 밤

밤에는 시야 제한 자체를 공포의 도구로 사용한다. 가로등, 창문 불빛, 차량 헤드라이트, 손전등, 달빛, 어두운 논·밭, 바다의 반사광을 활용한다.

모든 공간을 완전히 검게 만들지 않는다. 플레이어가 무엇이 있는지 알 것 같지만 확신할 수 없는 정도를 목표로 한다.

## 5. NPC 비주얼

### 5.1 기본 원칙

마을 주민은 괴물처럼 디자인하지 않는다.

> 평범한 사람이 90%, 이상함이 10%.

기본 주민은 실제 한국 농어촌에서 볼 법한 사람으로 구성한다. 중년·노년층 비중, 작업복, 점퍼, 장화, 모자, 농작업 복장, 어업/창고 작업복, 평범한 체형과 얼굴을 사용한다.

MakeHuman을 기본 인체 제작 파이프라인으로 사용할 수 있다.

### 5.2 기괴함

특정 NPC는 얼굴 자체보다 행동과 표정으로 기괴하게 만든다.

- 지나치게 긴 눈맞춤
- 늦게 깜빡이는 눈
- 미묘한 고개 기울임
- 입은 웃지만 눈은 웃지 않는 표정
- 대화가 끝났는데 계속 바라봄
- 플레이어가 지나간 뒤 천천히 고개를 돌림
- 멀리서는 가만히 서 있다가 가까워지면 움직임
- 뒤돌아본 사이 위치가 달라짐
- 평범하지 않은 idle pose
- 갑작스러운 방향 전환

얼굴을 괴물처럼 만드는 것은 후순위다.

### 5.3 희소성

모든 주민이 이상하면 이상함이 정상화된다.

- 대부분: 완전히 정상
- 일부: 미묘하게 이상함
- 특정 NPC: 명확하게 불안함
- 사건 관련 NPC: 특수 행동/연출

플레이어가 NPC를 계속 관찰하게 만드는 것이 목적이다.

## 6. 점프스케어

점프스케어는 게임 전체의 기본 공포 방식이 아니다. 기존 게임성 원칙인 느린 불안 80% + 짧은 급박/점프스케어 20%를 따른다.

갑자기 괴물이 화면을 채우는 방식보다 '평범한 사람이 갑자기 비정상적인 행동을 하는 것'을 우선한다.

예:
밤의 골목 → 가로등 아래 주민 → 그냥 지나감 → 뒤돌아봄 → 주민이 사라짐 → 골목 끝에 다시 보임 → 접근 → 갑작스러운 움직임/얼굴/대사.

점프스케어 이후에도 미스터리와 시스템이 계속되어야 하며 단순한 일회성 놀람으로 끝내지 않는다.

## 7. 괴담과 에피소드

### 7.1 1004개의 섬

1004는 실제 제작 맵 개수가 아니라 세계관의 확장 구조다.

1004개의 섬이라는 세계 → 각 섬은 하나의 에피소드 → 각 에피소드에는 하나 이상의 괴담/사건 → 서로 다른 환경과 공포 경험 → 일부 단서가 섬 사이의 큰 미스터리로 연결.

처음부터 1004개를 제작하지 않는다. Vertical Slice와 초기 시즌에서는 소수의 섬을 완성도 높게 제작하고 이후 에피소드를 추가한다.

### 7.2 한 섬에 여러 괴담

한 맵에 단 하나의 공포 소재만 넣지 않는다.

메인 사건 + 지역 괴담 + 주민들의 소문 + 오래된 기록 + 실제로 발생하는 이상 현상 + 사회적 갈등이 섞일 수 있다.

### 7.3 참고 소재의 재창작

실제 인터넷 괴담, 지역 전설, 체험담 등은 모티브로 사용할 수 있다. 산길에서 목격되는 정체불명의 사람/차량, 작은 마을의 저수지와 사망 사건, 무속과 관련된 공동주택 괴담, 염전과 노동 착취에 관한 미스터리, 폐교·폐시설 괴담, 어촌·선착장 괴담 등을 참고할 수 있다.

실제 사건·피해자·지역을 그대로 재현하지 않는다.

실제 괴담 → 핵심 공포 요소 추출 → 가상의 섬 → 가상의 인물 → 가상의 사건 → PROJECT 1028식 미스터리/게임플레이.

## 8. 환경과 공포의 관계

환경 자체가 공포를 설명하지 않는다. 플레이어가 익숙해진 공간을 공포 공간으로 재사용한다.

낮에는 '여기는 마을회관 앞'이던 장소가 밤에는 '왜 아무도 없지?', 조사 중에는 '낮에는 없던 흔적이 있다', 이동 중에는 '방금 저 창문에 사람이 있었는데?', 도주 중에는 '선착장으로 가야 하는데 길이 막혔다'로 변해야 한다.

주요 공간은 가능하면 낮의 정상 상태, 밤의 변화, 조사 상태, 사건 발생 상태를 모두 고려해 설계한다.

## 9. Blender / Astra 제작 원칙

Astra + Blender MCP를 사용할 경우 다음 순서로 제작한다.

### 9.1 Blockout

지형, 도로, 주요 건물, 밭, 비닐하우스, 창고, 선착장, 해안, 산/숲을 먼저 만든다.

### 9.2 생활 디테일

전봇대, 전선, 담장, 농기계, 차량, 어구, 생활용품, 표지판, CCTV, 잡초, 나무, 폐기물 등을 추가한다.

### 9.3 게임용 최적화

- 1 Blender Unit = 1 meter
- 반복 오브젝트는 가능한 경우 인스턴싱
- 충돌용 메시는 렌더 메시와 분리
- 오브젝트 이름을 의미 있게 지정
- 건물/도로/소품을 적절히 분리
- Unity에서 필요한 오브젝트만 활성화할 수 있도록 구성
- 최종 FBX/GLTF를 Unity로 가져오는 것을 전제로 한다

### 9.4 참조 이미지

참조 항공사진은 공간 구성과 생활감의 참고로 사용한다. 특정 실제 마을을 그대로 복제하지 않는다.

평면도는 공간 배치 기준, 항공사진은 건축·생활감 기준으로 분리한다.

## 10. 004 섬의 비주얼 방향

첫 Vertical Slice인 004는 한국 남서부 섬마을, 염전/농촌 작업 공간, 밀집 주거지, 창고, 비닐하우스, 밭, 산/경사, 선착장, 해안을 우선한다.

목표 크기는 기존 Vertical Slice 설계와 같이 약 250m × 250m 규모를 기준으로 한다.

004의 첫 인상은 공포 마을이 아니라 실제로 존재할 법한 작은 섬마을이어야 한다. 그 위에 주민 감시, 텃세, 실종/사건, 괴담, 야간 공포를 단계적으로 얹는다.

## 11. 하지 말아야 할 것

- 모든 주민을 괴물처럼 만들기
- 모든 장소를 어둡게 만들기
- 붉은 조명만으로 공포 만들기
- 피/시체를 반복적으로 배치하기
- 점프스케어를 반복하기
- 전형적인 일본식/서양식 호러 이미지를 그대로 사용하기
- 실제 지역과 실제 피해 사건을 그대로 복제하기
- 생활감 없는 예쁜 마을 만들기
- 모든 건물을 같은 방향/간격으로 배치하기

## 12. 최종 비주얼 목표

플레이어가 처음에는 '한국 시골을 정말 그럴듯하게 만들었네'라고 느껴야 한다.

조금 뒤에는 '뭔가 이상한데?'라고 느껴야 한다.

밤에는 '아까 저기에 사람이 있었는데?'라고 생각해야 한다.

사건을 조사하면서 '왜 이 마을 사람들은 내가 뭘 했는지 다 알고 있지?'라는 감각으로 넘어가야 한다.

최종적인 공포는 괴물에게 쫓기는 것이 아니라,

> 이 마을 전체가 나를 알고 있고, 나는 여기서 나갈 수 없다.

이다.
