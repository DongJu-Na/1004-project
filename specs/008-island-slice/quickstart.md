# Quickstart: 염전섬 수직 슬라이스

## 1. 자동 테스트
EditMode `Slice.Tests.EditMode` 5묶음 + 전체 회귀.

## 2. 씬
`Tools > PROJECT 1028 > Build Island Slice` → `Assets/Scenes/Island_Slice.unity` → Play. 스피커를 켠다(코드 합성 소리).

## 3. 한 런 (10~15분)
| 순서 | 할 일 | 기대 |
|---|---|---|
| 0 | 시작 | 상단: "창고에서 장부를 조사해 가져와라 · 창고까지 NNm · 출항까지 10:00". 30초간 조작 안내. 심박 느림 |
| 1 | 도로 따라 창고로 (도보 60~120초) | 도중 밀고자·집 앞 개(경계자) 지나감. 개 반경 → 소리·주변 NPC 회전. NPC가 보면 HUD 눈 표시·톡 소리 |
| 2 | 감시자가 보는 앞에서 창고 진입 | 붉은 맥동 + 소리, 감시자 의심↑. 안 보일 때 들어가면 조용 |
| 3 | 장부 앞 E 길게 | 진행률, 완료 시 장부 들기(두 손). 목표가 "부두로 돌아가 배를 타라"로 바뀜 + 확인음. 마커 이동 |
| 4 | 들고 돌아가기 | 보이면 쿨다운마다 의심↑, 심박 빨라짐. F 제압은 "두 손 필요" 거부. 트럭 탑승 가능(설정) |
| 5 | 밤 전환(5분) | 어두워짐·저음·안내. 밤에 돌아다니면 +1 |
| 6 | 누군가 3 도달 | "신고하러 간다 → 전화기" 라벨·경보. 선택: 제압(F, 장부 내려놔야)·앞질러 끊기(E)·내버려두기 |
| 7 | 출항 시각(10분) 부두 | 봉쇄 아니면 E → 성공 화면. 봉쇄면 "배가 뜨지 않는다" + 다음 배 3:00 카운트 → 못 풀면 강제 출도 |
| 8 | R | 재시작 |

## 4. 반응 점검 (F12 순환)
20종 이벤트 각각에 시각+청각 반응이 있는지 표로 체크(SC-004).
