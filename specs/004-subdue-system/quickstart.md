# Quickstart: 제압 시스템 검증

## 1. 자동 테스트
Test Runner EditMode → `Subdue.Tests.EditMode` 6묶음: HandRules(9조합), BackConeCheck, ShoveRoll, UnconsciousTimer, CostLedger, SubdueRulesValidator. 002·003 테스트 회귀 확인.

## 2. 씬
`Tools > PROJECT 1028 > Build Subdue Test Scene`. NPC: `W1 감시자`(등 돌림), `W2 감시자`(정면), `Q 침묵자`(제압 불가), `V 목격자(감시자)`; 물건 `Crate_A`(한 손), `Crate_B`(두 손); P1, P2. 좌상단 002 패널 + 우측 제압 패널(손 상태·기절 상태·발견자).

## 3. 시나리오
| US | 조작 | 기대 |
|---|---|---|
| 1 | 빈손, W1 뒤에서 F | 안내 "뒤에서 제압 [F]" → 즉시 기절, 로그 "소음 낮음". 물건 들고 F → "두 손이 필요" 거부. W2(나를 봄) 뒤에서 F → 정면 밀치기로 전환됨. Q에 F → "제압 불가" 무반응 |
| 2 | 빈손, W2 정면에서 F 20회(재생성 필요 없이 실패 시 반복) | 성공·실패 섞임, 실패 시 W2/P1=3. JSON failChance 0 → 전부 성공 |
| 3 | Crate_A 들고(E) W2에 F | 기절 + "소음 높음", 물건 유지. 빈손 F는 물건 동작 불가 |
| 4 | 기절 후 T(배속) | 90~180초 사이 깨어남 → W/P1=3, 신고 시도 로그. E로 들어 옮기기 → 두 손, 느림, 달리기 불가, 대화 안내 사라짐. G로 내려놓기 → 그 자리 |
| 5 | V가 보는 앞에서 제압 | 섬 +40 1회. V 시야 밖에서 제압 후 V가 기절자를 보게 이동 → 섬 +30, V/P1 +3(확정대기). 같은 V 재발견 없음. 목격한 V는 발견 +30 없음 |
| 코옵 | P1이 기절시킨 W1을 P2 위치로 옮겨 P2 시야에 두기 | (P2는 입력 없음) 패널에서 CarriedBy 표시 확인. 두 손 점유는 개체별 |
