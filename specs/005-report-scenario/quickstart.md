# Quickstart: 신고 시나리오 검증

## 1. 자동 테스트
EditMode `Report.Tests.EditMode` 5묶음 + 002~004 회귀.

## 2. 씬
`Tools > PROJECT 1028 > Build Report Test Scene`. 지점: `Phone_A`(가까움), `Phone_B`(멀리), `Office`(가장 멀리). NPC: `W1`, `W2`(감시자), `Q`(침묵자). 우측 하단 신고 패널.

## 3. 시나리오
| US | 조작 | 기대 |
|---|---|---|
| 1 | W1 정면에서 `I` 두 번(→3) | W1이 Phone_A로 걷기 시작, 라벨 "→ Phone_A". 도보 ≥ minWalkSeconds. Q를 3으로 올려도 이동 없음 |
| 2 | 개입 없이 대기 | 도착 → 신고 동작 → 섬 +25, 로그 "신고 완료". 다시 `I`해도 재신고 없음 |
| 3 | 이동 중 W1 뒤에서 `F` | 흐름 중단(기절). `T` 배속 → 깨어남 → 다시 걷기 시작 |
| 4 | W2를 3으로 올린 직후 Phone_A로 달려가 `E` 유지 | 진행률 표시, 이동하면 취소. 완료 → Phone_A 사용 불가, W2가 Phone_B로 재타깃. `cutRequiresTool` true + 도구 없음 → 거부, `K` 후 가능. Office에 `E` → 안내 없음 |
| 5 | Phone_A·B를 미리 끊고 Office를 씬에서 비활성화 후 W1 3 | 이동 없음, 로그 "포기: 지점 없음", 섬 변화 없음. Office 활성 시 → Office로 이동 |
| 코옵 | P2 시야·위치와 무관 | 어느 개체의 제압/끊기든 개입 가능(P2는 입력 없음 → 패널 확인) |
