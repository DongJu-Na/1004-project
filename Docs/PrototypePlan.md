# Prototype 실행 계획

## 목표

한 장의 테스트 씬에서 다음 10분 플레이 루프를 검증한다.

`도보 이동 → 차량 탑승 → 목적지 운전 → NPC 대화 → 보상 획득 → 저장`

## 구현 순서

1. 플레이어 이동, 카메라, 상호작용 기반
2. 차량 물리와 탑승/하차
3. NPC 대화와 단순 상태
4. 데이터 기반 미션 목표와 HUD
5. Timeline 컷신과 저장

## 완료 기준

- 키보드/마우스로 도보 이동과 카메라 회전이 자연스럽다.
- 차량을 타고 내릴 수 있고 충돌 후에도 조작이 깨지지 않는다.
- NPC와 대화해 목적지를 받는다.
- 목적지 도착 시 보상과 미션 완료가 표시된다.
- 재시작 후 저장된 진행 상태를 복구한다.

## 아직 범위 밖인 항목

전투, 다수의 NPC 스케줄, 래그돌, 온라인, 실제 섬 규모 맵, 복수 차량, 최종 아트/사운드는 Vertical Slice 이후로 미룬다.
